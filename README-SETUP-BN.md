# জনতার কথা — সেটআপ গাইড (বাংলা)

এই প্রজেক্টটি **Next.js 15 + TypeScript + Tailwind CSS** দিয়ে তৈরি — অর্থাৎ React অ্যাপ,
সরাসরি Vercel-এ পাবলিশ করা যাবে। ব্যাকএন্ড হিসেবে **Supabase** (PostgreSQL) ব্যবহার করা হয়েছে।

> ⚠️ Supabase ছাড়াও অ্যাপটি চলবে — তখন হার্ডকোড করা ডেমো ডেটা দেখাবে।
> কিন্তু রিপোর্ট/এলার্ট সংরক্ষণ করতে হলে Supabase সেটআপ করতেই হবে।

---

## ধাপ ১ — Supabase প্রজেক্ট বানান

1. [supabase.com](https://supabase.com) → **New Project** বানান
2. প্রজেক্ট খুলে বাম মেনু → **SQL Editor** → **New Query**
3. এই রিপোর `supabase/schema.sql` ফাইলের **পুরো লেখা** কপি করে পেস্ট করুন → **Run** চাপুন
   - ১২টা টেবিল + RLS পলিসি + `evidence` স্টোরেজ বাকেট + সিড ডেটা তৈরি হয়ে যাবে

## ধাপ ২ — API Keys সংগ্রহ করুন

Supabase Dashboard → **Project Settings** → **API**:
- **Project URL** → `NEXT_PUBLIC_SUPABASE_URL`
- **service_role** → **secret** key → `SUPABASE_SERVICE_ROLE_KEY` ⚠️ (এটা গোপন — কাউকে দেবেন না)

## ধাপ ৪ — Vercel-এ ইমপোর্ট করুন

1. [vercel.com](https://vercel.com) → **Add New** → **Project** → GitHub রিপো সিলেক্ট করুন
2. **Environment Variables**-এ এই ৩টা যোগ করুন:
   - `NEXT_PUBLIC_SUPABASE_URL` = ধাপ ২-এর Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = ধাপ ২-এর service_role key
   - `ADMIN_PASSCODE` = অ্যাডমিন প্যানেলের গোপন পাসকোড (নিজে বেছে নিন)
3. **Deploy** চাপুন — ২/৩ মিনিটে সাইট লাইভ!

> 💡 Supabase সেট না করে ডিপ্লয় করলে অ্যাডমিন প্যানেলে ডেমো পাসকোড `1234` কাজ করবে,
> কিন্তু Supabase সেট করার পর `ADMIN_PASSCODE` না দিলে লগইন বন্ধ থাকবে।

## ধাপ ৫ — অ্যাডমিন প্যানেল ব্যবহার

- ঠিকানা: `আপনার-সাইট.vercel.app/admin`
- পাসকোড দিয়ে লগইন করুন
- ট্যাবগুলো: **রিপোর্ট** (যাচাই/স্ট্যাটাস বদলান), **ক্যাটাগরি**, **স্বেচ্ছাসেবক**,
  **রক্তদাতা**, **SOS ইনবক্স**, **প্রমাণ**, **গাইড**, **আশ্রয়**
- রিপোর্টে স্ট্যাটাস বাটন চাপলেই (যাচাইকৃত / সমাধান চলছে / জরুরি) হোম ফিডে আপডেট হবে

## ফিচার তালিকা (বর্তমান)

1. **হোম ফিড** — রিপোর্ট কার্ড + ক্যাটাগরি ফিল্টার + জরুরি কল স্ট্রিপ + ভ্রমণ মোড টিজার
2. **সমস্যা জানান** — রিপোর্ট ফর্ম (বেনামী টগল, প্রমাণ লকার অপশন)
3. **জরুরি SOS** — ৯৯৯/১০৯/৩৩৩ এক-ট্যাপ কল, ৫০ জনে এলার্ট, নীরব SOS সেটআপ, ভুয়া কল স্ক্রিন
4. **ভ্রমণ মোড** — যাচাইকৃত গাইড + নিরাপদ আশ্রয়
5. **লাইভ ম্যাপ** — ঘটনা মার্কার + নিরাপদ রুট + এলাকা রেটিং ভোট
6. **পরিবার ট্র্যাকিং** — সদস্যদের অবস্থা কার্ড
7. **প্রমাণ লকার** — এনক্রিপ্টেড প্রমাণ তালিকা
8. **রক্তদাতা** — সক্রিয় দাতা + রক্তের অনুরোধ
9. **সমাধান ট্র্যাকার** — পৌরসভার আপডেট (হোমে)
10. **স্বেচ্ছাসেবক লিডারবোর্ড** (হোমে)
