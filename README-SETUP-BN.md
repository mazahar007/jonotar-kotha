# জনতার কথা — সেটআপ গাইড (বাংলা)

এই প্রজেক্টটি **Next.js 15 + TypeScript + Tailwind CSS** দিয়ে তৈরি — অর্থাৎ React অ্যাপ,
সরাসরি Vercel-এ পাবলিশ করা যাবে। ব্যাকএন্ড হিসেবে **Supabase** (PostgreSQL) ব্যবহার করা হয়েছে।

> ⚠️ Supabase ছাড়াও অ্যাপটি চলবে — তখন হার্ডকোড করা ডেমো ডেটা দেখাবে।
> কিন্তু রিপোর্ট/এলার্ট সংরক্ষণ করতে হলে Supabase সেটআপ করতেই হবে।

---

## ধাপ ১ — Supabase প্রজেক্ট বানান

1. [supabase.com](https://supabase.com) → **New Project** বানান
2. প্রজেক্ট খুলে বাম মেনু → **SQL Editor** → **New Query**
3. এই রিপোর `supabase/schema.sql` ফাইলের **পুরো লেখা** কপি করে পেস্ট করুন → **Run** চাপুন
   - ১২টা টেবিল + RLS পলিসি + `evidence` স্টোরেজ বাকেট + সিড ডেটা তৈরি হয়ে যাবে
4. তারপর **আরেকটা New Query** খুলে `supabase/schema-v2-locations.sql` চালান (Phase 2)
   - লোকেশন হায়ারার্কি টেবিল (বিভাগ/জেলা/উপজেলা/থানা/ইউনিয়ন) + রিপোর্টে লোকেশন
     কলাম ও `media_urls` + পাবলিক `media` স্টোরেজ বাকেট (ছবি/ভিডিও আপলোডের জন্য)
   - সিড: সব ৮টি বিভাগ, ময়মনসিংহ বিভাগের ৪ জেলা, ময়মনসিংহ জেলার ১৩ উপজেলা,
     ময়মনসিংহ সদরের কোতোয়ালী মডেল থানা ও বর্তমান ১২টি ইউনিয়ন
5. তারপর **আরেকটা New Query**-তে `supabase/schema-v3-members-surveys.sql` চালান (Phase 3)
   - `members` (সদস্য নিবন্ধন), `surveys` (এলাকার জরিপ) ও `survey_responses`
     (ভোট) টেবিল তৈরি হবে
   - ⚠️ এই ফাইল না চালালে নিবন্ধন/জরিপ ডেমো মোডে চলবে (ডেটা স্থায়ী হবে না)
6. সবশেষে **আরেকটা New Query**-তে `supabase/schema-v4-roads.sql` চালান (Phase 4)
   - `roads` (এলাকাভিত্তিক রোড) ও `road_updates` (লাইভ আপডেট) টেবিল তৈরি হবে
   - সিড: ময়মনসিংহ সদরের ৫টি রোড ও তাদের সাম্প্রতিক আপডেট
   - ⚠️ এই ফাইল না চালালে রোডের অবস্থা ডেমো মোডে চলবে (ডেটা স্থায়ী হবে না)

> 📍 **ধাপে ধাপে লোকেশন ডেটা:** বাকি জেলা/উপজেলা/থানা/ইউনিয়নের তথ্য ধাপে ধাপে
> যোগ হবে — অ্যাডমিন প্যানেলের **লোকেশন** ট্যাব থেকে (বিভাগ → জেলা → উপজেলা →
> থানা/ইউনিয়ন) অথবা নতুন seed SQL ফাইল দিয়ে। গঠন (schema) পুরো বাংলাদেশের
> জন্য তৈরি; Phase 1-এ শুধু ময়মনসিংহের ডেটা দেওয়া হয়েছে।

## ধাপ ১.৫ — সদস্য, জরিপ ও "আমার এলাকার মানুষ" (Phase 3)

- **নিবন্ধন (`/register`)** — নাম + মোবাইল নম্বর + নিজ এলাকা (স্থায়ী) + বর্তমান
  এলাকা দিয়ে সদস্য হওয়া যায়। পরিচয় = ফোন নম্বর (OTP নেই); পরে একই নম্বর
  দিয়ে আবার প্রবেশ করা যায়। ফোন নম্বর **কখনো** অন্য সদস্য/পাবলিককে দেখানো
  হয় না — শুধু অ্যাডমিন প্যানেলের **সদস্য** ট্যাবে দেখা যায়।
- **জরিপ (`/surveys`)** — অ্যাডমিন **জরিপ** ট্যাব থেকে প্রশ্ন + ২–৬টি অপশন +
  এলাকা-পরিধি (সারা দেশ / বিভাগ / জেলা / উপজেলা / থানা / ইউনিয়ন) দিয়ে জরিপ
  তৈরি করেন। যেসব সদস্যের **নিজ এলাকা** ওই পরিধির মধ্যে, শুধু তারাই ভোট দিতে
  পারেন — প্রতিজন একবার। ভোটের পর ফলাফল (% বার) দেখা যায়। অ্যাডমিন ফলাফলে
  **থানাভিত্তিক ও ইউনিয়নভিত্তিক** বিভাজনও দেখতে পান।
- **আমার এলাকার মানুষ (`/amar-elaka`)** — সদস্যদের নিজ এলাকা বনাম বর্তমান
  এলাকা মিলিয়ে **স্বয়ংক্রিয়** হিসাব: মোট সদস্য, কজন নিজ এলাকায়, কজন অন্য
  এলাকায় আছেন + নামের তালিকা (শুধু যারা "দেখান" চালু রেখেছেন)।
  ⚠️ বর্তমান এলাকা = সদস্যের **নিজের দেওয়া** তথ্য (প্রোফাইল থেকে বদলানো
  যায়) — এটি GPS লোকেশন **নয়**।
- **ধাপে ধাপে চালু:** প্রথমে ময়মনসিংহ সদর দিয়ে শুরু করুন — সেখানকার সদস্যরা
  নিবন্ধন করলে জরিপ ও "আমার এলাকার মানুষ" সক্রিয় হয়ে যাবে। নতুন এলাকার
  ডেটা (লোকেশন ট্যাব) যোগ হলেই সেই এলাকার মানুষও একই সুবিধা পাবেন।

## ধাপ ১.৭ — এলাকাভিত্তিক রোডের অবস্থা (Phase 4)

- **রোডের অবস্থা (হোম সেকশন + `/roads`)** — হোম পেজে আলাদা সেকশনে এলাকা
  (বিভাগ → জেলা → উপজেলা → থানা → ইউনিয়ন) বেছে সেই এলাকার রোডগুলোর বর্তমান
  অবস্থা দেখা যায়: ভালো / মোটামুটি / ভাঙা-ঝুঁকিপূর্ণ / মেরামত চলছে / যানজট /
  জলাবদ্ধ / বন্ধ — রঙিন ব্যাজসহ, সাথে স্ট্যাটাসভিত্তিক সারসংক্ষেপ।
- **লাইভ আপডেট** — প্রতিটি রোডের বর্তমান অবস্থা = তার **সর্বশেষ আপডেট**।
  যে কেউ রোডের পেজে গিয়ে (`/roads/[id]`) নতুন অবস্থা + বিবরণ + চাইলে ছবি দিয়ে
  আপডেট দিতে পারেন; আগের সব আপডেট টাইমলাইনে থেকে যায়।
- **অ্যাডমিন** — **রোড** ট্যাব থেকে নতুন রোড যোগ/এডিট/মুছে ফেলা এবং যেকোনো
  আপডেট মুছে (মডারেশন) করা যায়। নতুন এলাকার রোড সেভাবেই ধাপে ধাপে যোগ করুন।

## ধাপ ৪ — Vercel-এ ইমপোর্ট করুন

1. [vercel.com](https://vercel.com) → **Add New** → **Project** → GitHub রিপো সিলেক্ট করুন
2. **Environment Variables**-এ এই ৩টা যোগ করুন:
   - `NEXT_PUBLIC_SUPABASE_URL` = ধাপ ২-এর Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = ধাপ ২-এর service_role key
   - `ADMIN_PASSCODE` = অ্যাডমিন প্যানেলের গোপন পাসকোড (নিজে বেছে নিন)
3. **Deploy** চাপুন — ২/৩ মিনিটে সাইট লাইভ!

> 💡 Supabase সেট না করে ডিপ্লয় করলে অ্যাডমিন প্যানেলে ডেমো পাসকোড `1234` কাজ করবে,
> কিন্তু Supabase সেট করার পর `ADMIN_PASSCODE` না দিলে লগইন বন্ধ থাকবে।

## ফিচার তালিকা (বর্তমান)

1. **হোম ফিড** — রিপোর্ট কার্ড + ক্যাটাগরি ফিল্টার + জরুরি কল স্ট্রিপ + ভ্রমণ মোড টিজার
2. **সমস্যা জানান** — রিপোর্ট ফর্ম (বেনামী টগল, প্রমাণ লকার অপশন, এলাকা নির্বাচন, ছবি/ভিডিও সংযুক্তি)
3. **জরুরি SOS** — ৯৯৯/১০৯/৩৩৩ এক-ট্যাপ কল, ৫০ জনে এলার্ট, নীরব SOS সেটআপ, ভুয়া কল স্ক্রিন
4. **ভ্রমণ মোড** — যাচাইকৃত গাইড + নিরাপদ আশ্রয়
5. **লাইভ ম্যাপ** — ঘটনা মার্কার + নিরাপদ রুট + এলাকা রেটিং ভোট
6. **পরিবার ট্র্যাকিং** — সদস্যদের অবস্থা কার্ড
7. **প্রমাণ লকার** — এনক্রিপ্টেড প্রমাণ তালিকা
8. **রক্তদাতা** — সক্রিয় দাতা + রক্তের অনুরোধ
9. **সমাধান ট্র্যাকার** — পৌরসভার আপডেট (হোমে)
10. **স্বেচ্ছাসেবক লিডারবোর্ড** (হোমে)
11. **সম্পূর্ণ রেসপন্সিভ (Phase 2)** — মোবাইলে আগের মোবাইল ভিউ; ডেস্কটপে সাইডবার
    নেভিগেশন + প্রশস্ত মাল্টি-কলাম লেআউট (হোমে ডান রেল, ম্যাপে পাশের প্যানেল)
12. **লোকেশন হায়ারার্কি (Phase 2)** — বিভাগ → জেলা → উপজেলা → থানা → ইউনিয়ন;
    রিপোর্ট ফর্মে ক্যাসকেডিং সিলেক্টর, কার্ডে এলাকা-ক্রম (ব্রেডক্রাম্ব)
13. **ছবি/ভিডিও আপলোড (Phase 2)** — রিপোর্টে সর্বোচ্চ ৪টি মিডিয়া (Supabase
    Storage `media` বাকেট); Supabase ছাড়া ডেমো মোডে লোকাল প্রিভিউ
14. **সদস্য নিবন্ধন (Phase 3)** — নাম + ফোন + নিজ/বর্তমান এলাকা; প্রোফাইলে
    বর্তমান এলাকা বদলানো ও দৃশ্যমানতা টগল; ফোন নম্বর সম্পূর্ণ ব্যক্তিগত
15. **এলাকার জরিপ (Phase 3)** — এলাকাভিত্তিক জরিপ, নিজ এলাকার সদস্যদের
    একবার ভোট, ফলাফল বার; অ্যাডমিনে থানা/ইউনিয়নভিত্তিক বিভাজন
16. **আমার এলাকার মানুষ (Phase 3)** — নিজ এলাকার সদস্যদের স্বয়ংক্রিয়
    হিসাব (কে নিজ এলাকায়, কে অন্য এলাকায়); বর্তমান এলাকা স্ব-ঘোষিত, GPS নয়
17. **এলাকাভিত্তিক রোডের অবস্থা (Phase 4)** — হোমে আলাদা সেকশন + `/roads`;
    এলাকা ফিল্টারে রোডের বর্তমান অবস্থা (৭টি স্ট্যাটাস), নাগরিকদের লাইভ

## লোকাল ডেভেলপমেন্ট

```bash
npm install
```

```bash

```
